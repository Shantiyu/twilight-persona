# 魔法体系、可爱标志与神器

## 各族群的魔法

| 族群 | 能力 |
|---|---|
| 陆马 Earth pony | 与土地、作物、体力相连；无角无翼，但耐力与力量出众 |
| 飞马 Pegasus | 飞行、操纵天气、在云上行走；云中城与天气工厂是其文明核心 |
| 独角兽 Unicorn | 用角施法：悬浮、照明、护盾、变形、瞬移等；威力取决于天赋与训练 |
| 天角兽 Alicorn | 兼具三者能力，寿命极长；数量极少（Celestia、Luna、Cadance、Twilight、Flurry Heart） |
| 水晶小马 Crystal pony | 与水晶之心共鸣，皮毛如水晶般反光 |
| 其他 | 幻形灵的变形与情感吸食、龙族的龙火（可寄送信件/物品）、Discord 的混沌魔法、斑马的草药与药剂 |

## 独角兽魔法的常见形式

- **Telekinsis / 悬浮**：最基本的能力，Twilight 常用它同时搬运大量书籍。
- **光照与照明**：角尖发光。
- **护盾**：Twilight 的招牌防御术。
- **瞬移（teleport）**：Twilight 的专长之一。
- **变形／转换**：高阶且危险（可爱标志互换、物体变形都属于此类）。
- **咒语研究**：魔法可以被"写下来"——书、卷轴、Star Swirl 的未完成咒语都是剧情关键道具。
- **天赋差异**：Twilight 的可爱标志本身就是"魔法"，属于极为罕见的特例。

## 可爱标志（Cutie Mark）

- 出现在小马后腰，象征其"特殊天赋"被发现的一刻。
- 与社会身份深度绑定；没有可爱标志的小马（如 CMC 早期）会因此焦虑。
- 可爱标志可以被魔法强行夺走或交换——这正是 Starlight 的"平等镇"与《Magical Mystery Cure》的核心冲突。
- Cutie Mark Crusaders 的使命：先是找到自己的标志，后来变成帮助其他小马找到／理解自己的标志。

## 和谐元素（Elements of Harmony）

六块宝石，各自代表一种品质：

| 元素 | 持有者 |
|---|---|
| 诚实 Honesty | Applejack |
| 善良 Kindness | Fluttershy |
| 欢笑 Laughter | Pinkie Pie |
| 慷慨 Generosity | Rarity |
| 忠诚 Loyalty | Rainbow Dash |
| 魔法 Magic | Twilight Sparkle |

- 六者齐聚时能发动强大的"和谐之光"，是击败 Nightmare Moon、Discord 等威胁的关键。
- 历史渊源：更早的时代由"Equestria 的柱石"（Pillars of Equestria，包括 Star Swirl the Bearded、Rockhoof、Mage Meadowbrook、Flash Magnus、Somnambula、Mistmane）持有，他们将元素之力种入**和谐之树**。
- S4 首播中，Mane Six 把元素归还给和谐之树；此后元素不再以宝石形态随身携带。
- S9 中和谐之树与元素被 King Sombra 摧毁（后续走向以剧集为准），主角团的"友谊"本身成为真正的力量来源。

## 关键神器与道具

| 名称 | 作用 |
|---|---|
| **Crystal Heart（水晶之心）** | 水晶帝国的核心，保护帝国免受黑暗侵袭 |
| **Alicorn Amulet（天角兽护符）** | 赐予强大但腐蚀心智的魔法（Trixie 曾使用） |
| **Staff of Sameness（平等杖）** | Starlight 用来夺走可爱标志的道具 |
| **Mirror Pool（镜像池）** | 复制放入其中的对象／生物 |
| **Cutie Map（可爱地图）** | 友谊城堡中的桌子地图，会标记需要解决友谊问题的地点，派 Mane Six 出任务 |
| **Journal of Friendship（友谊日志）** | 主角团互相留言的日记，S4 之后取代给 Celestia 的信 |
| **Equestria Girls 的魔法镜** | 连接小马世界与人类世界，每 30 个月亮周期开启一次 |
| **Star Swirl 的时间咒语** | S5 末 Starlight 用它改写过去，导致多条黑暗时间线 |
| **Grogar 的铃铛（Bewitching Bell）** | S9 中能吸取与转移魔法的古神器 |
| **彩虹力量（Rainbow Power）** | S4 末宝箱开启后获得的力量形态 |

## Equestria Girls 支线设定

- Twilight 通过水晶帝国的魔法镜进入人类世界，变成人类少女，在 **Canterlot High School** 就读。
- **Sunset Shimmer**：Celestia 的前学生，第一部反派，后成为人类世界主角团领袖与 Twilight 的重要朋友。
- 人类世界的对应角色（Sci-Twi、人类 Applejack 等）与小马世界角色**不是同一人**，设定上要区分。
- 后续剧场版引入塞壬三姐妹（Dazzlings）、水晶预科学院（Crystal Prep）、魔法晶石（geodes）等。

## 使用魔法设定作为比喻时的注意

可以用"和谐元素需要六种品质"来说明团队互补，用"可爱标志"来说明"找到自己的专长"，用"咒语要写下来才能复用"来说明文档化。但**不要**把魔法当作现实问题的解释或解决方案。
