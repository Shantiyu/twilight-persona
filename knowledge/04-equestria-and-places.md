# 小马国地理、地标与节庆

## 总体格局

- **Equestria（小马利亚，社区常称"小马国"）**：由 Princess Celestia 与 Princess Luna 共治的王国，昼夜由她们分别升起太阳与月亮。国土以 Ponyville、Canterlot 一带为中心，四周有狮鹫、龙、牦牛、骏鹰等邻国与族群。
- **小马三大族群**：陆马（earth pony，与土地、农作、体力相通）、飞马（pegasus，掌管天气、能在云上行走）、独角兽（unicorn，以角施法）。天角兽（alicorn）兼具三者能力，数量极少。
- 其他族群：水晶小马、幻形灵、狮鹫、龙、牦牛、骏鹰／海马、斑马、驴、水牛等。

## 核心地点

### Ponyville（小马镇）
Twilight 从 Canterlot 搬来后长期居住的地方，也是整个系列的主舞台。
- **Golden Oak 图书馆**：Twilight 最初的住处与图书馆，S4 末被 Tirek 摧毁。
- **Castle of Friendship（友谊城堡）**：S4 末从和谐之树所赠的宝箱中产生，成为 Twilight 的新家；内部有**可爱地图（Cutie Map）**。
- **Sweet Apple Acres**：Apple 家族的农场。
- **Carousel Boutique**：Rarity 的时装店。
- **Sugarcube Corner**：蛋糕夫妇的甜品店，Pinkie Pie 在此工作与居住。
- **Ponyville 学校 / 市政厅 / 医院 / 温泉**：日常剧情的常见场景。

### Canterlot（坎特洛特）
建在山腰的首都，公主们的居城所在。
- **皇家城堡**：Celestia 与 Luna 的王座厅、花园（Discord 石像曾立于园中）。
- **天才独角兽学校（School for Gifted Unicorns）**：Twilight 的母校与入学考试现场（Spike 在此孵化）。
- **Canterlot 精品店（Rarity 分店）**、Donut Joe 的甜甜圈店。

### Cloudsdale（云中城）
飞马的城市，天气工厂所在地；Rainbow Dash 与 Fluttershy 的故乡与飞行训练营所在。

### Everfree Forest（永恒自由森林）
不受小马控制、天气与生物自行其是的野生森林。
- **Two Sisters 古堡（Castle of the Two Sisters）**：Celestia 与 Luna 的旧居，和谐元素曾存放于此。
- **和谐之树（Tree of Harmony）**：位于森林深处的洞穴中，是和谐元素的来源。
- Zecora 的小屋也在林中。

### Crystal Empire（水晶帝国）
北方的水晶小马国度，由 Princess Cadance 与 Shining Armor 治理；核心宝物是**水晶之心（Crystal Heart）**。标志性活动是水晶集市（Crystal Faire）。

### 其他常出现的地方
- **Manehattan**（大都会，Rarity 分店、Coco Pommel）
- **Appleloosa / Dodge Junction**（西部拓荒小镇）
- **Las Pegasus、Fillydelphia、Baltimare、Vanhoover、Trottingham**（被提及的城市）
- **Sire's Hollow**（Starlight 与 Sunburst 的故乡）
- **Griffonstone**（狮鹫的破败家园，Gabby 与 Gilda 来自这里）
- **Yakyakistan**（牦牛王国，Yona 的家乡）
- **Dragon Lands（龙之域）**（龙族聚居地，Ember 为龙领主）
- **Mount Aris / Seaquestria**（骏鹰与海马的居所）
- **Changeling Hive（幻形灵巢穴）**
- **Klugetown**（2017 剧场版中的沙漠港城）

## 历法与节庆

| 名称 | 说明 |
|---|---|
| Summer Sun Celebration | 夏至庆典，纪念 Celestia 升起太阳／Luna 回归；S1 首播的背景 |
| Winter Wrap Up | Ponyville 用人工方式迎接春天的清扫仪式 |
| Nightmare Night | 对应万圣节，纪念 Nightmare Moon 传说 |
| Hearth's Warming Eve | 对应圣诞节，纪念三个族群建国与"炉火之心" |
| Hearts and Hooves Day | 情人节等价物 |
| Grand Galloping Gala | Canterlot 的年度盛大晚宴 |
| Running of the Leaves | 秋季落叶赛跑 |
| Sisterhooves Social | 姐妹搭档的趣味运动会 |
| Equestria Games | 小马国运动会（水晶帝国举办） |
| Best Young Flyer Competition | 飞马新秀赛 |

## 世界规则要点（可作为比喻素材）

- 天气由飞马"工厂"制造与安排，Ponyville 等地的四季因此可控。
- 可爱标志（cutie mark）出现即代表小马发现了自己的天赋；这在社会中意义重大。
- 每个族群有自己的文化偏见与刻板印象，剧情反复处理的正是"跨族群的理解"（S8 友谊学校的主线）。
